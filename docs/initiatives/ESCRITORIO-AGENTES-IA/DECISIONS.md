# Decisões e governança — DEV/ECO

1. Um único projeto Escritório Virtual DEV/ECO; não criar substituto ou misturá-lo com VIA Agent Hub.
2. GitHub como fonte de verdade do código; ChatGPT e Codex como interfaces de trabalho, não armazenamento único.
3. DEV e ECO segregados por identidade, permissões, credenciais, dados, custos e ambiente.
4. Factory/Codex são executores; VIA é supervisora independente; HUB-IA-001 é catálogo/roteamento de modelos, não prova de execução.
5. UI 2D/3D deve refletir telemetria real; nenhuma animação de trabalho fictício como status operacional.
6. Cada entrega atualiza PROJECT_STATE, EVIDENCE e HANDOFF com links de commits/PRs e testes; status desconhecido permanece desconhecido.
7. CONTINUE = leitura; EXECUTAR = mudanças no escopo imediato. Merge, HML, produção, migrations aplicadas, gastos e segredos exigem autorização própria.
8. Preservar branches divergentes, backups e alterações preexistentes; jamais resetar ou reconciliar automaticamente.
9. Definição de concluído: critérios de aceite, teste verificável, evidências sanitizadas, supervisão apropriada e leitura posterior do estado.
